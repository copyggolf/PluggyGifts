# Power of Gifts With Pluggy

เว็บเกมภาษาไทยสำหรับมือถือและคอมพิวเตอร์ เปิด dist/index.html ผ่าน HTTP server หรือโฮสต์ dist/ บน static hosting ได้ทันที ไม่มีขั้นตอน build และไม่มี API key

## กติกา
- Catch: 3 รอบ รอบละ 30 วินาที รับ +10 พลาด −5 สายไฟ −50 (5 ตัว/รอบ) The1 +100 (ครั้งเดียวในรอบที่ 2)
- Buster: 3 รอบ รอบละ 30 วินาที โปรโมชัน +10/+25/+50/+100 ปลั๊กกี้ −20
- Shuffle: 5 ครั้ง กล่อง 3–7 ใบ ถูก +50 ผิด −20 การสลับเร็วขึ้นตามรอบ

ชื่อและประวัติคะแนนเก็บใน localStorage ของผู้เล่น ไม่มีฐานข้อมูลส่วนกลาง ไม่มีการแลกรางวัล มีปุ่มแชร์ผ่าน share sheet หรือ clipboard และลิงก์ไป Power Buy

ภาพปลั๊กกี้ต้นฉบับได้รับจากโฟลเดอร์ Google Drive ที่ผู้ใช้ระบุ: Pluggy-0010, Pluggy-0013, Pluggy-0101 ส่วนภาพเครื่องใช้ไฟฟ้าเป็น SVG ที่วาดสำหรับเว็บนี้ ป้าย The1 ในเกมเป็นข้อความ ไม่ใช่ไฟล์โลโก้ทางการ

## การควบคุม
Catch: ลากนิ้ว/เมาส์ ปุ่มลูกศร หรือปุ่มซ้ายขวาบนจอ
Buster: แตะ/คลิก หรือเลข 1–9
Shuffle: แตะ/คลิก หรือเลขตำแหน่งจากซ้ายไปขวา
เกมหยุดชั่วคราวเมื่อหน้าเว็บถูกซ่อนหรือเสียโฟกัส

## เผยแพร่
Sites ใช้ .openai/hosting.json สำหรับ identity และ dist/ สำหรับไฟล์ที่เผยแพร่
สามารถนำ dist/ ไปใช้ GitHub Pages, Cloudflare Pages หรือ static hosting อื่นได้
